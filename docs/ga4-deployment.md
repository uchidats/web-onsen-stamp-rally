## 既存公開版での実通信確認

既存の`Analytics`コミット（`8f2c525`）が既にmainとGitHub Pagesに反映されていたため、履歴の変更や同じ実装の重複追加は行わない。今回の検証記録を `Add privacy-conscious Google Analytics 4` という新しい通常コミットで記録する。

新しいEdgeプロファイルで実際の公開サイトとGoogle公式gtag.jsを使用し、テスト用ページビューを1件送信した。

| 確認項目 | 結果 |
| --- | --- |
| 公開ページとanalytics.js | HTTP 200、導入コードあり |
| 同意前のGoogle通信 | 0件 |
| 同意後のgtag.js | 正しい測定ID、1回、HTTP 200 |
| 同意後のpage_view | 1回、正規URLのみ |
| GA4 collectの応答 | HTTP 204 |
| 同意ボタン連打・検索・設定の再表示 | ページビューの追加なし |
| JavaScript例外 | 0件 |

ブラウザのログにはcollectのHTTP 204応答後の `net::ERR_ABORTED` も記録された。ここで確認したのはGoogle収集エンドポイントのHTTP応答とリクエスト件数であり、GA4管理画面のレポートへの反映確認ではない。管理画面のリアルタイム表示は所有者側で確認できる。

この記録にはCookieの識別子・セッションID・訪問記録・認証情報を含めない。公開後は最新コミットに対応するGitHub Pagesデプロイの完了、公開ファイルの一致、同意前後の実通信を改めて確認する。
