# GA4導入と公開後の確認

測定ID：`G-5P0Y0M7SNM`。`index.html`のheadで`analytics.js`を読み込み、同意した公開URLでのみGoogle公式gtag.jsを追加します。[公開時の検証記録](ga4-deployment.md)も参照してください。

## 計測条件と同意

- 対象はHTTPSの `uchidats.github.io/web-onsen-stamp-rally/` と同ディレクトリの`index.html`。localhost、127.0.0.1、IPv6ローカル、file://、他のプロジェクトやプレビューは計測しません。
- 全地域で同意するまでGoogleタグも計測リクエストも送らないBasic Consent Modeを使用します。広告の保存・広告へのユーザーデータ利用・広告のパーソナライズは常にdeniedです。
- 許可・拒否の選択は専用localStorageキー`onsen-analytics-consent-v1`へ180日間保存します。期限切れ・壊れた設定・保存先が使えない場合は自動で許可しません。保存が使えなくても、その画面での明示的な許可は有効です。
- フッターから選択を変更できます。取り消し時はGAの無効化フラグを立て、解析用Cookieだけを削除し、Googleタグをアンロードするためページを再読み込みします。温泉の記録は変更しません。過去に送信したデータの削除は別の手続きです。

独自ドメインを追加するときは`analytics.js`の`config.sites`に`hostname`と末尾スラッシュ付きの正規`path`を追加し、GA4側のデータストリームも更新してください。ホストの部分一致や「ローカル以外すべて」の判定は使いません。

## 送信データと重複防止

`send_page_view:false`で初期化時の自動ページビューを停止し、公式タグの読み込み成功後に`page_view`を1回送ります。初期化と送信にはそれぞれガードがあるため、連打・スクリプトの二重実行・設定の再表示で二重送信しません。ページの通常の再読み込みは新しいページビューです。

送信するページURLはサイトの正規URLに固定し、検索クエリ・ハッシュ・流入元URLは送りません。タイトルも固定です。`user_id`、`user_properties`、温泉ID、訪問履歴・訪問日・メモ、フォーム値、Googleアカウント情報を送るコードはありません。Google Signalsと広告パーソナライズ信号も無効にしています。

Googleタグ自体はCookie識別子やブラウザ・端末情報などを処理します。「匿名で何も個人に関係する情報を送らない」という案内はしません。サイト内に通知とGoogleのプライバシー説明へのリンクを設置しています。

## GA4管理画面で必要な設定

このリポジトリからはGA4プロパティの設定を変更できません。公開前に対象Webデータストリームの**拡張計測をオフ**にしてください。特にブラウザ履歴変更のページビュー、サイト内検索、フォーム操作、外部クリック、スクロール、動画、ファイルダウンロードを有効にしないでください。`send_page_view:false`だけではプロパティ側の拡張計測は無効になりません。

GA4が標準で生成する`session_start`、`first_visit`などの内部イベントと、このサイトから追加するイベントは別です。サイトはページビュー以外の独自イベントを送りません。管理画面でもGoogle Signals・ユーザー提供データの収集を有効にせず、データ保持期間や削除窓口を運営方針に合わせて設定してください。海外展開時は通知の翻訳と地域ごとの必要事項を見直してください。

## 検証

ローカルのテストでは本番ホスト判定、同意前の通信ゼロ、測定ID、1回の送信、個人データへのアクセスなし、拒否・取り消し・有効期限・保存失敗を確認します。ブラウザテストは公開URLへのアクセスをローカルの変更内容に差し替え、Googleへの通信を検証用スタブに置き換えて実データを汚さず確認します。

公開後は、本番URLを開き、同意前はNetworkに`gtag/js`とGAの`collect`がないこと、許可後に正しいIDの`gtag/js`が読み込まれること、`page_view`が1回であることを確認してください。GA4のリアルタイム画面で受信も確認します。未公開のローカル変更について、公開サイトの受信確認済みとは扱いません。

参考：[GoogleのBasic Consent Mode手順](https://developers.google.com/tag-platform/security/guides/consent?consentmode=basic)、[ページビューと拡張計測の重複防止](https://developers.google.com/analytics/devguides/collection/ga4/views)。
