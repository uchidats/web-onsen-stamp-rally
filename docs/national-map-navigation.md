# 全国SVG地図のズーム・移動

全国地図の右上に「＋」「－」「全体表示」「関東・東北」を配置。ボタンは地図を覆わない専用行に置く。

- 拡大・縮小は1.5倍刻み、倍率は1〜8倍。表示範囲を元のSVGの範囲内に制限する。
- PCはドラッグ、スマートフォンは1本指で移動、2本指でピンチズーム。
- Ctrl／⌘＋ホイールでカーソル位置を中心にズーム。通常のホイールはページをスクロールする。スマートフォンのページスクロールは地図の外側で行う。
- 初期表示は既存の「関東・東北」プリセットと同じ範囲。「全体表示」は日本全国へ切り替える。表示状態は保存せず、再読み込みで「関東・東北」表示になる。

メルカトル投影の結果は変更せず、SVG全体のviewBoxだけを変更する。県の輪郭と67施設の中心には常に同じ表示変換を適用する。マーカー径は画面上で約8〜11pxに保ち、施設別の位置補正は行わない。

8pxを超える移動とピンチはクリック扱いにしない。近接施設の選択UIとキーボード操作を維持する。Chromeのタッチ対象補正には、実際のタッチ開始座標からのヒット判定で対応する。

座標・固定ID・訪問記録・達成率・検索・県別Leaflet地図・出典表示は変更していない。

検証用テスト: `tests/japan-map.test.cjs`、`tests/e2e-national-navigation.test.cjs`、既存の `tests/e2e-new-coordinates.test.cjs`。

2026-10-14の検証結果:

- 単体テスト28件成功。保存・復元、達成率、フィルター、GA同意管理、座標・出典を含む。
- Chromeの1280px／390pxで全国図134回、県別図150回の施設選択が成功。
- ボタン、プリセット、ドラッグ、ピンチ、倍率制限、Ctrlホイール、通常ホイール・地図外スワイプのページスクロール、ズーム後の県のクリック／タップとキーボード選択、再読み込みでの初期化が成功。
- 全67マーカーの中心と共有メルカトル変換との誤差は0.1画面px未満。黄金崎不老ふ死温泉の選択と密集地点の選択UIを確認。
- SVG生成を再実行しても輪郭・投影・出典ファイルの差分なし。座標、固定ID、県別地図、保存処理にも差分なし。

密集地点でのChromeのタッチ対象補正による誤選択は修正し、全施設の再テストで成功。地図外スワイプ後のテストでは慣性スクロール終了を待ってから次のタップを検証する。実機スマートフォンでの手動操作確認は未実施。
